# Z-View 资产管理平台 v1.3

企业级 IT 资产管理、终端监控与远程运维平台

---

## 🎯 系统简介

Z-View 提供自动化资产采集、实时终端监控、健康度评估、软件资产管理等功能。

说明：程序品牌名已统一为 `Z-View`，但为了兼容历史部署，Windows 服务名、安装目录和 `ProgramData` 数据目录仍保留 `CMDB-Agent`。

**核心特性**:
- ✅ 自动化资产采集（Agent）
- ✅ 实时终端监控和健康度评估
- ✅ 软件资产管理和统计
- ✅ 灵活的分组管理
- ✅ GPO域策略自动部署

---

## 📦 系统组成

### 后端服务
- **assets_api.py** - FastAPI后端服务（端口8080）
- **config.json** - 系统配置文件
- **requirements.txt** - Python依赖

### Agent程序
- **cmdb_agent_unified.py** - 信息采集Agent
- **GPO部署包/** - 打包好的EXE和部署脚本

### 前端应用
- **frontend/** - Vue 3 + Element Plus前端

### 文档
- **文档/** - 完整的系统文档

---

## 🚀 快速启动

### 1. 启动后端
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python assets_api.py
```

访问: http://localhost:8080/docs

### 2. 启动前端
```bash
cd frontend
npm install
npm run dev
```

访问: http://localhost:3000

### 3. 部署Agent
使用GPO域策略自动部署，详见 `文档/GPO部署完整指南.md`

## 🎯 核心功能

### 仪表板
- 资产统计概览
- 软件安装排行Top 10

### 终端概览（核心页面）
