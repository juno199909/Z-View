### 生产态正式运行

正式推荐：

- `CMDB-Agent` Windows 服务
- 服务命令：`Z-View.exe --service-host`
- 服务工作子进程：`Z-View.exe --run-agent --no-remote-desktop`
- 用户会话代理：由 supervisor 自动拉起 `Z-View.exe --user-session-agent`

### 角色说明

- `--service-host`
  - 仅作为 Windows Service 宿主
- `--run-agent --no-remote-desktop`
  - 负责采集、上报、策略、任务执行
  - 启动用户会话 supervisor
- `--user-session-agent`
  - 负责远控 WebSocket、托盘、授权弹窗
  - 默认占用 `9000`

## 生产环境 Agent 验证

检查服务：

```cmd

```

检查进程：

```cmd

```

检查 9000：

```cmd
netstat -ano | findstr ":9000"
```

检查 supervisor 日志：

```cmd
type C:\ProgramData\CMDB-Agent\logs\agent-runtime.log
```

## 注意事项

1. 浏览器不再直接连终端 `9000`，而是统一走平台代理，再由平台转发到终端 Agent。
2. 远控端口 `9000` 默认应由 `--user-session-agent` 持有，不应由后台 worker 持有。
3. 无登录用户时，默认不会有授权弹窗，也通常不会监听 `9000`。
4. 如果心跳正常但远控不可用，先查 `agent-runtime.log` 是否有 supervisor 拉起失败日志。
5. 域环境正式部署请优先使用 [deploy.bat](/c:/Users/Administrator/Desktop/IT2026/IT2026/GPO部署包/deploy.bat)，不要再维持双计划任务。
6. 兼容性目标仍是 `Windows 7 / 10 / 11`，排障时端口检查优先使用 `netstat -ano`。
