## 迁移规则（事故教训制度化）

1. **每次只迁一个内聚子系统**，旧单体位置保留薄委托 shim（同 cmdb_agent_layout.py 模式）
2. **每步验证**：py_compile（SyntaxWarning 即错）→ pyflakes → 沙箱 E2E（kilo_tmp\test_layout_updater.py）→ 生产冒烟
3. **frozen 打包入口不变**：cmdb_agent_unified_v2.py 仍是 build spec entry，zvagent 包随 import 自动收集
4. **测试 patch 目标**：沙箱测试 patch `zvagent.layout` 模块属性（不是 shim 的重导出绑定）
5. **依赖注入优先**：迁移的函数通过参数收 logger/路径（同 hygiene.py 模式），避免跨模块全局单例
