## 🐛 如果遇到问题

### 前端问题

**问题**: 页面显示错误或功能不正常
**解决**:
```powershell
# 停止前端
Ctrl + C

# 清理缓存
rm -r node_modules
rm package-lock.json

# 重新安装
npm install

# 启动
npm run dev
```

### 后端问题

**问题**: API返回错误
**解决**:
```powershell
# 停止所有Python进程
Stop-Process -Name python -Force

# 重新启动
cd c:\Users\Administrator\Desktop\IT2026
python assets_api.py
```

### Agent问题

**问题**: 网关仍然显示"未检测到"
**解决**:
1. 确认使用的是最新版本EXE（13:50打包的）
2. 查看文件修改时间
3. 如果不是最新版，重新复制

**问题**: 仍然上报404
**解决**:
1. 检查后端API是否运行
2. 测试: `Invoke-WebRequest -Uri "http://localhost:8080/api/v1/assets/stats"`
3. 如果返回200，则API正常
