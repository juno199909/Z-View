## 🎯 系统概述

Z-View 是一个企业级 IT 资产管理和终端监控系统，提供：
- 自动化资产采集
- 实时终端监控
- 健康度评估
- 软件资产管理
- 分组管理
- 告警中心

---

## 📦 系统架构

### 技术栈
- **前端**: Vue 3 + Element Plus + Vue Router
- **后端**: Python + FastAPI + MySQL
- **Agent**: Python + psutil + PyInstaller
- **部署**: GPO域策略自动部署

### 组件
1. **前端应用** (端口5173) - 用户界面
2. **后端API** (端口8080) - 业务逻辑和数据接口
3. **MySQL数据库** (端口3306) - 数据存储
4. **Agent程序** (端口9000) - 终端信息采集和远程控制

## 🔌 后端API

### 资产管理
- `GET /api/v1/assets` - 获取资产列表（支持搜索、筛选、分页）
- `GET /api/v1/assets/{id}` - 获取资产详情
- `GET /api/v1/assets/{id}/detail` - 获取资产完整详情（含心跳、软件）
- `PUT /api/v1/assets/{id}` - 更新资产
- `DELETE /api/v1/assets/{id}` - 删除资产（软删除）
- `POST /api/v1/assets/batch-delete` - 批量删除资产
- `GET /api/v1/assets/stats` - 资产统计

### Agent接口
- `POST /api/v1/agent/heartbeat` - Agent心跳上报

### 分组管理
- `GET /api/v1/groups` - 获取分组列表
- `POST /api/v1/groups` - 创建分组
- `PUT /api/v1/groups/{id}` - 更新分组
- `DELETE /api/v1/groups/{id}` - 删除分组

### 软件管理
- `GET /api/v1/software/stats` - 软件安装统计

### 其他
- `GET /` - 健康检查
- `GET /docs` - API文档（Swagger）

## 🚀 部署方式

### 1. 前端部署
```bash
cd frontend
npm install
npm run build
# 部署dist目录到Web服务器
```

### 2. 后端部署
```bash
cd backend
pip install -r requirements.txt
python assets_api.py
# 或使用systemd/supervisor管理
```

### 3. Agent部署

**方式1: GPO域策略**
1. 将部署包放到SYSVOL: `\\DC\SYSVOL\domain\scripts\CMDB\`
2. 创建GPO启动脚本指向 `deploy.bat`
3. 链接到目标OU
4. 客户端重启后自动部署

**方式2: 手动部署**
1. 复制 `Z-View.exe` 到目标机器
2. 运行即可（无需配置）

## 🐛 故障排查

### 常见问题

**1. Agent无法连接服务器**
- 检查防火墙是否开放8080端口
- 检查服务器地址是否正确
- 检查网络连通性

**2. 终端显示离线**
- 检查Agent是否运行
- 检查最后心跳时间
- 查看Agent日志

**3. 软件清单为空**
- Agent需要首次运行6小时后才上报软件
- 或重启Agent强制上报

**4. 分组修改失败**
- 检查分组是否存在
- 检查网络连接
- 查看浏览器控制台错误

**5. 删除按钮无效**
- 刷新页面（Ctrl+F5）
- 检查后端API是否正常
- 查看浏览器控制台错误
