## 3. 会话建立流程（TCP 主路径，当前生效）

```
观看端                    平台 assets_api(8080)                 被控端 Agent(9000)
   │ POST /api/v1/remote/sessions     │                                │
   │ {asset_id, fps_limit}             │                                │
   │──────────────────────────────────►│                                │
   │                                   │ 创建 remote_sessions 行         │
   │◄── session_id + session_token ────│                                │
   │    + ws_url + wt_url + wt_cert_hash                                │
   │                                   │                                │
   │ ① 优先尝试 WebTransport(UDP/4433)  │      【当前已禁用，见 §6】       │
   │ ② 失败/禁用 → WebSocket(TCP) 回落  │                                │
   │ ws(s)://host/api/v1/remote/sessions/{id}/ws?token=…                │
   │──────────────────────────────────►│  relay_browser_to_agent        │
   │                                   │ ────── ws://asset_ip:9000 ────►│
   │                                   │ ◄────── RD 引擎会话 ───────────│
   │                                   │   (ConsentUI 免确认自动放行)     │
   │ ◄═══ remote_capabilities ═════════│◄═══ screen_info ═══════════════│
   │ ◄═══ JPEG/H264 视频帧 ════════════│◄═══ 采集帧 ═════════════════════│
```

- 会话令牌 `session_token` 仅存哈希（DB `remote_sessions.session_token`），URL 携带一次性 token。
- 平台中间件鉴权（P0-02）：JWT → 角色权限 → Scoped RBAC 范围校验（`/api/v1/assets/{id}/*` 路径正则卡口）。
- 引擎侧 consent：`CONSENT_MANAGER` → ConsentUI 管道 → 托盘设置 `skip_consent_for_session=true` 时自动放行（`session_skip_enabled`）。

## 4. 帧协议（应用层，传输无关）

**双向统一帧格式**（TCP WS 消息边界 / WT 字节流均按此解析）：

```
[4B 大端长度 len][1B 帧类型 type][payload len 字节]
  type=0：text —— JSON 控制消息（remote_capabilities/screen_info/settings/ack/…）
  type=1：binary —— 视频帧（JPEG: 0xFFD8 起；H264: Annex-B 包组）
```

- WebSocket(TCP) 模式：每条 WS 消息即一个完整帧（有消息边界）。
- WebTransport 模式：WT 流是**无边界字节流**，观看端适配器内置重组缓冲（`buffer` + 长度前缀解析，见 WebRemoteDesktop.vue `reader.read()` 循环）；会话流的线格式为 `[0x41 WEBTRANSPORT_STREAM 帧][session_id 变int][应用帧…]`，网关剥离首部 session_id 变int 后按应用帧转发。

### 控制消息（type=0 JSON，节选）

| 方向 | type | 说明 |
|---|---|---|
| 引擎→观看端 | `remote_capabilities` | 剪贴板/文件传输/Shell/分辨率控制能力位 |
| 引擎→观看端 | `screen_info` | 屏幕尺寸/显示器信息 |
| 观看端→引擎 | `settings` | 画质预设（high→CRF19/均衡→23/流畅→28 映射）、质量、fps、scale |
| 双向 | `ack` | H264 背压（sent_seq/acked_seq/ack_times） |
| 观看端→引擎 | `clipboard_set/get`、`file_*` | 剪贴板与文件传输 |
| 观看端→引擎 | `shell_exec` / `shell_stop` | **远程终端**（PowerShell，CRF 编码修正+输出缓冲） |
| 引擎→观看端 | `shell_output` / `shell_exit` / `sas_result` | 终端输出/退出/SAS 结果 |

## 5. 采集管线（被控端）

架构：`service_user_agent_split_phase2`——采集**权威在服务托管助手**（`session_helper_capture` 优先），本地回退在远程桌面路径被禁用。

```
capture_frame 请求（引擎 → 服务特权管道 CMDB-Agent-Privileged）
  → 服务 session_manager 分发 → 高完整性助手（用户会话内）
  → 抓屏（管线候选: dxgi → wgc → dwm → mss → gdi → imagegrab → pyautogui）
  → H264 编码（助手侧直编，省 JPEG 往返）→ 包回传
```

- **虚拟显示**：无物理屏/分辨率控制场景自动供给（`mm.inf` IddSampleDriver，pnputil 安装+scan-devices）。
  - VMware 等环境可能驱动装不上（`driver_package_ready_install_pending` 死循环）→ 用 `ZVIEW_DISABLE_VIRTUAL_DISPLAY=1`（机器级环境变量+服务重启）禁用，改用真实显示器采集。
  - **坑**：驱动安装需重启完成；重启后仍 pending 的机器（如 2213 的 VMware）需排查该环节。
- **画质预设映射**（1.9.45+）：预设 → H264 CRF（high=19/balanced=23/smooth=28）+ 推流缩放上限（1.0/0.85/0.7），`custom` 交还 QoS 自适应；编码器随 CRF/fps/分辨率变化热重建。
- **QoS 背压**：仅由真实 inflight 积压驱动降档（ACK 速率不可作为依据——CPU 产能不足时帧率本来就低）；「传输模式=手动」时禁用 QoS 自动降档。

## 7. 同意与安全

### 7.1 同意（Consent）双路径

```
引擎 CONSENT_MANAGER._show_consent_dialog
  ├─ helper 管道路径：CMDB-Agent-Consent-{n} → ConsentUI 管道服务端
  │    └─ 先查 load_tray_settings()：allow_remote_requests=false 拒绝；
  │       skip_consent_for_session=true 自动放行（reason=session_skip_enabled）
  └─ ConsentUI 进程内直调路径：_patched_show_consent_dialog
       └─ (1.9.47+) 已补齐相同检查 ✓ —— 两路径口径一致
```

- 托盘菜单「本机免确认（自动允许）」= `user_session_settings.json` 的 `skip_consent_for_session`。
- **坑**：远程修改该 JSON 禁用 PowerShell `Set-Content -Encoding UTF8`（写入 BOM 会让 `json.load` 失败被静默吞掉 → 设置回退默认）。`load_tray_settings` 已改 `utf-8-sig` 容忍。

### 7.2 P0-03 特权管道 fail-closed

`IPC/named_pipe.py _handle_client` 校验顺序（fail-closed）：
1. `GetNamedPipeClientSessionId` → 与服务 expected_session 比对（pipe_session_id）；
2. 不可用时 `ProcessIdToSessionId`（process_session_id）；
3. 均不可用（pywin32 已知问题）→ `_is_trusted_client_process`：客户端镜像路径 vs 服务 `sys.executable`。
   - **坑（已修）**：服务经 `current` 目录 Junction 启动而客户端解析为 `versions\<ver>\` 真实路径，`abspath` 不解析 Junction → 误拒。已改 `os.path.realpath`（解析 Junction）。

### 7.3 证书与令牌

| 机制 | 说明 |
|---|---|
| 一机一密 | Agent 与平台双向认证（heartbeat/批量命令携带） |
| 平台 JWT | 控制台会话令牌（角色权限 + Scoped RBAC 分组范围） |
| WT 证书 | 持久根 CA（zview-root，10 年）签发叶子（11 天轮换，ECDSA P-256）；观看端 `serverCertificateHashes` 指纹校验（指纹随会话 API 下发）——**无需导入根证书** |

### 9.4 已知坑（运维铁律）

1. **WT 网关重启前杀光全部 `webtransport_gateway` 进程**（僵尸多进程同时绑定 4433 → QUIC 包随机投递 → 时好时坏）；启动后验证 4433 owner 唯一。
2. **网关/服务改代码后必须重启对应进程**（py_compile 通过 ≠ 生效）；核对端口 owner 的进程 start time。
3. **证书轮换后必须重启 WT 网关**（内存证书不热更）。
4. 远程改 JSON 配置**禁用 PS `Set-Content -Encoding UTF8`（写 BOM）**；读侧已用 `utf-8-sig` 容忍。
5. 前端 axios `request` 客户端 baseURL 已含 `/api/v1`，调用勿重复拼前缀。
6. 临时脚本改源码用 write 工具（PS 管道 `-replace|Set-Content` 损坏 UTF-8）。
