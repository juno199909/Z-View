## 一、项目概述

**Z-View**：面向企业 IT 运维场景的**终端管理与远程运维平台**，由四大能力域组成：

```
资产管理（CMDB）+ 软件中心/策略 + 终端安全管控 + 远程桌面运维
```

| 维度 | 规模 |
|---|---|
| 主后端（Python/FastAPI） | assets_api.py 7,120 行 + 挂载模块 + 2 个独立 API（8081/8082），约 1.5 万行 |
| Agent 被控端（Python） | 约 30 文件，2.6 万行（最大 session_manager.py 4,287 行、remote_desktop_engine_v2.py 4,060 行） |
| 前端（Vue 3 + Element Plus） | 51 个 .vue，src 约 1.7 万行（核心 WebRemoteDesktop.vue 4,404 行） |
| 数据库 | MySQL 库 `cmdb`，约 37 张表 |
| Agent 版本 | 1.5.0（cmdb_agent_core.py:147），部署 84 台终端 |
| Git | 唯一仓库根 `D:\IT2026\IT2026`，代码根为内层 `IT2026\IT2026\IT2026` |

## 三、后端架构（平台侧）

### 3.1 技术栈

- **Web 框架**：FastAPI + uvicorn（8080 自带 auth 中间件 + CORS；8081/8082 各自独立进程同款结构）
- **数据库**：mysql.connector 裸 SQL（**无 ORM/SQLAlchemy**），库 `cmdb`，时区 +8:00
- **认证**：auth_utils.py（796 行）**全自研**——HMAC-SHA256 自包含 token（b64url，非 pyjwt）、PBKDF2 加盐哈希（12 万次迭代）、用户存 JSON 文件 auth_state.json、RBAC 三角色（admin/operator/viewer）× 20+ 权限点、agent_token 校验（env/file/legacy）
- **其他**：websockets（WS 中继/客户端）、pysnmp（网络发现，可选）、requests、aioquic（WebTransport）、cryptography（QUIC 证书）
- **支撑模块**：config_utils.py（.env + DB 配置 + 密钥文件生成）、console_utils.py（Windows 控制台 UTF-8 防乱码）

### 3.2 文件清单

| 文件 | 行数 | 角色 |
|---|---|---|
| assets_api.py | 7,120 | 主后端（8080），约 60 条路由；挂载 security/remote-desktop/agent-upgrade 三个子 API（L6943-6968） |
| security_api.py | 1,841 | 终端安全管理，`APIRouter(prefix=/api/v1/security)`，34 端点，启动幂等建 10 张 security_* 表 |
| remote_desktop_api.py | 251 | 远控会话管理 `/api/v1/remote/sessions`（创建/查询/删除） |
| agent_upgrade_api.py | 198 | Agent 升级 `/api/v1/agent/upgrade`（upload/status/download/delete） |
| software_management_api_complete_v2.py | 3,071 | 软件中心（8081），39 端点 |
| software_policy_api.py | 1,469 | 软件策略（8082），10 端点，`/check/{asset_id}` 对 Agent 免认证 |

### 3.3 assets_api（8080）路由分组

- **认证/用户**：login、me、change-password、users CRUD（首登强制改密、token_version 改密即失效旧 token）
- **资产**：CRUD、批量删除、CSV 导出、stats/options、status/history/changes/uptime/detail、command、trigger-report
- **批量运维**：batch/execute、history、results
- **发现**：ping/SNMP 异步扫描 → 导入（幂等）
- **告警**：alerts 列表/统计/处置/批量处置/导出（severity 过滤）
- **日志**：logs POST（Agent 上报）/GET/stats/export（system_activity_logs，event_time 必须显式 NOW()）
- **Agent 对接**（agent_token 鉴权）：heartbeat（约 600 行，含告警判定、版本上报、upgrade 指令下发）、policies、security-events/status/policies/policy-result
- **远控**：会话创建 + 两条 WS 代理（旧版按资产直代理；新版按 session_token 状态机 created→connecting→connected→disconnected，DB 只存 SHA256(token)，断开即失效）

### 3.4 Agent 自动升级链路（agent_upgrade_api + 心跳）

1. admin `POST /upload`（exe+version）→ 存 `agent_upgrade/{version}/Z-View.exe`，流式 SHA256 + manifest.json（现存 1.3.0→1.5.0 共 21 个版本目录，该目录不入 Git）
2. Agent 心跳上报 `agent_version` → 写 assets.agent_version
3. 版本不一致 → 心跳响应携带 `{version, sha256}` upgrade 指令
4. Agent `GET /download?version=`（agent_token）→ 自替换（见 §5.3）

### 3.5 关键工程约束（历史踩坑沉淀）

- FastAPI **固定路径路由必须声明在参数路由之前**（/events/stats 在 /events/{id} 前）——8081/8082/8080 均已遵守
- INSERT 前必须前置校验外键目标存在（404 而非让 MySQL 外键报 500）；枚举/IP 校验失败返回 422、重复 IP 返回 409
- 重启后端必须后台启动（Start-Process），否则阻塞工具调用
- auth 完全自研无第三方依赖；全部裸 SQL

## 五、Agent 被控端架构

### 5.1 进程拓扑（单一 exe 分角色，入口 cmdb_agent_unified_v2.py，1,884 行）

| 角色 | 启动参数 | 会话 | 职责 |
|---|---|---|---|
| 服务宿主 | 无参/`--service-host` | Session 0, LocalSystem | ServiceRuntime + 心跳 worker 子进程（崩溃 2s 自动重启） |
| Agent worker | `--run-agent` | Session 0 | 采集/心跳/软件管理/安全策略同步 + 9001 控制面 |
| UserSessionAgent | `--user-session-agent` | 用户会话 | 9000 远控 WS 服务端（挂掉 `os._exit(1)` 由服务拉回） |
| ConsentUI | `--consent-ui` | 用户会话 | 托盘图标 + TaskDialog 远控确认框 |
| HighIntegrityHelper | `--high-integrity-helper --target-session-id N` | SYSTEM | 抓帧 + SendInput 输入注入（命名管道服务端） |

**会话监督**：SessionManager（RemoteService/session_manager.py，4,287 行）每 15s 枚举 WTS 会话，按"角色互斥锁（Global\ 命名互斥体）+ 心跳 JSON 文件（5s 写/45s 过期）+ PID 精确匹配"三重判定，缺则 `WTSQueryUserToken + CreateProcessAsUser` 拉起（20s 冷却）。

**通信**：命名管道（IPC/named_pipe.py，421 行，DACL = SYSTEM+Admins+会话用户，客户端会话校验 fail-open）：
- 服务管道 `CMDB-Agent-Privileged`：ping/拓扑/ensure_virtual_display/capture_frame 等
- 会话 Helper 管道 `CMDB-Agent-Privileged-Session-{id}`：6 种白名单消息（ping / describe_desktop_context / capture_frame / inject_mouse_event / inject_keyboard_event / release_input_state）
- Consent 管道：multiprocessing.connection + authkey=HMAC(token|hostname|salt)

**帧数据流**：观看端 WS → UserSessionAgent(9000) → 服务管道 → Helper 抓帧（可直出 H.264）→ 两跳管道回传 → WS 发出。

### 5.2 心跳与周期任务（cmdb_agent_core.py，1,846 行）

| 任务 | 周期 | 说明 |
|---|---|---|
| 心跳 | 30s（策略可调 5s~7d） | POST /api/v1/agent/heartbeat，携带 IP/MAC/CPU/内存/磁盘/agent_version；响应可带 policies + upgrade 指令 |
| 硬件上报 | 86400s | 失败 60s 重试 |
| 软件清单 | 30s | 注册表 Uninstall 键采集，走心跳接口 report_type=software |
| 安全策略同步 | 300s（下限 60s） | GET /api/v1/agent/security-policies，应用 firewall/usb/app_control/file_protect/behavior 五类并回传结果 |
| 软件任务轮询 | 30s | 8081 /tasks/poll；下载（断点续传+SHA256）→ install/uninstall → 回传 stdout/stderr |
| 平台策略 | 心跳下发热应用 | intervals、远控 consent 策略、UAC 安全桌面开关；持久化 ProgramData\CMDB-Agent\runtime\agent-policies.json |

9001 控制面（Bearer token HMAC 比对）：`/api/v1/command`（shell）、`/api/v1/security-command`（security_manager 分发 20 种命令）、`/api/v1/trigger-report`。

### 5.3 自动升级自替换（perform_self_upgrade）

下载 → SHA256 校验 → 备份 `.upgrade-old` → 生成独立 bat（net stop → taskkill → 替换 exe → net start，失败回滚）→ DETACHED 启动 → `os._exit(0)`。当前版本 1.5.0。

### 5.4 安全能力（security_manager.py，SYSTEM 权限执行）

| 子模块 | 实现方式 |
|---|---|
| 防火墙 | netsh advfirewall 规则下发/删除/枚举（+PowerShell Get-NetFirewallRule） |
| USB 管控 | 注册表 USBSTOR\Start 3↔4 存储类禁用/启用 + WMI 枚举设备（VID/PID）台账 |
| 进程管控 | psutil 扫描 + 黑名单匹配告警；按 pid/name taskkill |
| FIM 文件保护 | 目录 MD5 基线（≤2000 文件）+ 比对（modified/created/deleted），>50 处变更判 mass_change（勒索软件告警） |
| 行为采集 | 启动项（Run 键）/服务（sc query）/网络连接 |
| 终端隔离 | block-all-inbound + 放行 9001/3389 |

**策略解析算法**（assets_api `agent_get_security_policies`）：global ∪ group ∪ asset 三级绑定，每组取 `priority DESC → scope(asset3>group2>global1) → id DESC` 第一条生效（last-match-wins，确定性 tie-breaker）；disabled 不参与；撤销覆盖=删 binding。

## 六、远程桌面链路（当前核心，引擎 v2）

### 6.1 编码与 QoS

- **编码器**（Codec/h264_encoder.py）：PyAV/FFmpeg；后端探测 `h264_nvenc→h264_qsv→h264_amf→libx264`（真实编码一帧验证+缓存）；libx264：preset=ultrafast、tune=zerolatency、threads=4、无 B 帧、gop≈2s；硬编映射码率（CRF18→8M/22→6M/26→4M/32→2M）；RGB→YUV 强制 BT.709（修颜色偏差）
- **QoS 档位**（每 1.5s 评估）：high CRF21 / medium CRF24 / low CRF28，默认 medium。**降档仅由真实背压驱动**（inflight = sent−acked > 12 连续 2 次）；升档需 inflight<4 且 ack_rate 达标连续 3 次；会话建立 3s 内不评估（防启动噪声误判）。动态分辨率：编码 EMA>30ms 降采样、<15ms 回升；inflight>30 丢非关键帧
- **H.264 激活/降级**：观看端 `viewer_capabilities{webcodecs:true}` 激活；12s 无 frame_ack 或编码连续失败 5 次 → 回落 JPEG

### 6.2 传输与协议

- **控制消息**（JSON 文本帧）：mouse/keyboard/viewer_capabilities/frame_ack/request_keyframe/settings/clipboard_*/file_*/ping；服务端下发 screen_info/consent_result/codec_switch/remote_capabilities 等
- **二进制帧**：JPEG `[0x02][4B frameId][4B w][4B h][4B len][jpeg]`；H.264 `[0x03][4B seq][4B w][4B h][4B len][1B keyframe][Annex-B]`（大端，比 base64 省 33%）
- **观看端连接策略**（WebRemoteDesktop.vue）：优先 WebTransport/QUIC（证书 hash 钉扎，4s 超时，连续 2 失败禁用 5 分钟）→ 回落 WS：HTTPS 页面强制 wss 平台中继（5173 → vite ws 代理 → 8080 → ws 透传 Agent:9000），HTTP 页面可先直连 `direct_ws_url`（终端IP:9000）；断线指数退避自动重连 + 心跳

### 6.3 抓屏与显示基底修复

- 主路径：服务 Helper 会话内直抓毫秒级；本地兜底链 mss→gdi→dxgi→wgc→dwm→imagegrab→pyautogui（2s 超时降级）
- **Parsec-VDD 虚拟显示器修复**：连续 3 次空帧/输入后画面停滞时触发，对 installed_detached 等状态执行 ensure→repair（pnputil/devcon + 设备 enable），15s 冷却 + 签名去重；`ZVIEW_DISABLE_VIRTUAL_DISPLAY=1` 可关闭（防 VMware 死循环）。驱动载荷随包于 Drivers/VirtualDisplay/
- **DWM 唤醒 hack 已废弃**（RedrawWindow/分层窗口 alpha pulse 会轰炸 explorer.exe 致 AppHangB1），改为 H.264 恒定帧率微小增量帧 + 心跳重发

### 6.4 输入注入

remote_desktop_protocol.py 归一化鼠标消息（坐标 0~1、按键 0/1/2、wheel ±12）→ DPIAwareMapper 反归一化 → 优先 Helper `inject_mouse_event`/`inject_keyboard_event`（SYSTEM，可触 UAC 安全桌面），失败回退本地 SendInput/pyautogui；文本用 KEYEVENTF_UNICODE 绕输入法；输入单线程执行器 + move 合并。支持剪贴板双向、文件上传/下载。

## 九、通信协议与安全汇总

| 通道 | 协议 | 鉴权 | 加密 |
|---|---|---|---|
| 前端→平台 | REST + wss（vite 同源代理） | HMAC 用户 token / session_token（DB 存 SHA256） | HTTPS/wss（自签证书，域内导入信任） |
| 前端→平台（远控备选） | WebTransport/QUIC UDP 4433 | session_token + 证书 hash 钉扎 | QUIC TLS（ECDSA P-256，14 天自动续期） |
| 平台→Agent | HTTP/WS | agent_token（全网共用，已知局限） | 内网明文（平台侧 uvicorn 无 ssl，靠部署层） |
| 服务↔Helper | 命名管道 | DACL(SYSTEM+Admins+会话用户) + 会话校验 fail-open | 本机 |
| 平台/前端↔MySQL | TCP 3306 | DB 账号（.env） | 内网 |
